# BurnDown

## Task 1 (Need to Show on Monday)

- Create a new GitHub account from scratch
    - Complete the GitHub account registration
    - Verify the newly created account
    - Configure the basic GitHub account settings
- Configure SSH authentication
    - Generate a new SSH key pair
    - Add the SSH public key to the GitHub account
    - Configure the local SSH agent
    - Verify the SSH connection with GitHub
- Create a new GitHub repository
    - Create a fresh repository under the newly created GitHub account
    - Configure the repository settings
    - Add an initial README file
- Clone the repository
    - Clone the newly created repository using SSH
    - Verify the repository was cloned successfully
    - Verify the remote repository URL
    - Check the Git repository status
- Make changes to the repository
    - Create or modify files
    - Review the changes
    - Check the Git status
    - Review the Git diff
- Commit the changes
    - Stage the changes
    - Create a meaningful commit message
    - Verify the commit history
- Push the changes to GitHub
    - Push the committed changes to the remote repository
    - Verify the push was successful
    - Verify the changes are visible on GitHub
- Verify the complete Git workflow
    - Verify the local repository is connected to the correct GitHub repository
    - Verify SSH authentication works correctly
    - Verify commits are synchronized with GitHub
    - Verify the local and remote repositories are up to date

## Task 2

- Run and practice all the basic Linux commands provided in the `learning/SE-Batch-001/Docs/basics/linux-commands.md` file.
- Execute each command locally in your WSL environment and make sure you understand what the command does, its purpose, and when it should be used.
- Practice the commands hands-on by creating files and directories, navigating through the filesystem, managing files, checking system information, working with processes, permissions, networking, and other basic Linux operations.
- Complete your practice and be prepared to demonstrate what you have learned by Wednesday.
- You will have both an oral and practical test on Thursday, where you will be expected to explain the commands and execute them in your WSL environment.
